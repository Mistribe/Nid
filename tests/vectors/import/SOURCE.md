# Import batch vectors

- `worked-examples.nid.json`: the three worked examples of `docs/subscription-data-model.md` as a `nid.data` file
  (the content of `tests/Nid.Subscriptions.IntegrationTests/Import/GoldenFile.cs`, plus an email and a note). One
  amount is a JSON number with a trailing zero (`17.20`).
- `batching.nid.json`: 1 201 entities in one section, generated by `tests/Nid.Platform.Tests/ImportVectorsTests.cs`.
- `batches.json`: every batch of both files (slices of 500 in file order, sections sorted by name), with the
  `UnambitiousFx.Engram` (`JsonCanonicalizer.Hash`) hash of its `entities` array. The browser's batches must match
  (`web/src/features/import/prepare.test.ts`; web design §6.3). Regenerate with `NID_REGENERATE_VECTORS=1`.
