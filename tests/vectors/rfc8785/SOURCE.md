# RFC 8785 test vectors

- `official/`: copied from https://github.com/cyberphone/json-canonicalization (`testdata/input`, `testdata/output`)
  at commit 19d51d7fe467d4706a3ff08adf8a748f29fc21e0, under the Apache License 2.0 (`official/LICENSE`). Unmodified.
- `numbers.txt`: RFC 8785 Appendix B, "Number Serialization Samples", one `ieee-hex,expected` pair per line;
  `expected` is `error` for NaN and infinities.
- `corpus.json`: generated by `tests/Nid.Platform.Tests/CorpusGenerator.cs` (fixed seed). Expected values are
  produced by `UnambitiousFx.Engram` (`JsonCanonicalizer`), whose own suite passes the two sets above; the browser
  test (`web/src/lib/canonical-json.test.ts`) still reads both. 1E's browser canonicalizer
  must reproduce every entry byte for byte (`docs/superpowers/specs/2026-09-23-import-protocol-design.md` §6).
