This guide is for someone who already has **a server with Docker**, **a domain name** and **a reverse proxy** that terminates TLS (Caddy, Traefik, nginx…). To try Nid on your own computer first, `http://localhost:8080` is enough, with no proxy and no domain.

The images are public on `ghcr.io/mistribe/nid`, for amd64 and arm64, no account needed: `latest`, `X.Y.Z`, or `X.Y` for its latest patch. Each carries a signed provenance attestation.

The interface is in French for now; English is coming soon. The reference documentation, [`deploy/README.md`](https://github.com/Mistribe/Nid/blob/main/deploy/README.md), is in French too.

## Two setups

| | Standalone | Reference |
|---|---|---|
| Files | one compose file and one `.env` | a compose file, a setup script, secrets |
| Sign-in | identifier and password kept by Nid, optional two-step verification | passkeys, through Pocket ID |
| Host names | one | two (Nid and Pocket ID) |
| Backup | up to you: a copy of the Docker volumes, and the JSON export of your figures | encrypted every night, with a restore test (`restore.sh --verify`) |

**Start with the standalone** if in doubt: it runs with four commands. The reference setup adds passkeys and automatic backups.
