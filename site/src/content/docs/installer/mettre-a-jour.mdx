Chaque fusion dans Nid est une version. Les migrations de la base s'appliquent au démarrage de `nid`.

## Standalone

Dans le dossier `deploy/standalone`, avec les mêmes profils qu'à l'installation : `docker compose pull && docker compose up -d --remove-orphans`.

## Référence

1. **Sauvegardez** :

```bash
docker compose -f deploy/compose.yaml exec backup nid-backup backup-now
```

2. `git pull`.
3. `docker compose -f deploy/compose.yaml up -d --build` (avec `-f deploy/compose.override.yaml` si vous en avez un).

Le détail, dont le passage depuis les anciennes images `nid-api` et `nid-web` : [`deploy/README.md` §5](https://github.com/Mistribe/Nid/blob/main/deploy/README.md#5-mettre-à-jour).
